# HouseMaster: демонстрационные страницы (R04-0.4, прототип «Объект», R07 площадь комнаты)

Публикуется через GitHub Pages. Корень: `index.html` со ссылками; страницы: `r04/` (замер длины по фото) `object/` (окно «Объект») и `room/` (R07, площадь комнаты по углам). Все пути относительные, поэтому работает в подпапке репозитория.

Это исследовательские прототипы, не часть приложения HouseMaster Camera. Секретов в файлах нет; данные пользователя остаются на телефоне.

Источники (в приватном репозитории проекта): `research/cam-meas-r04/` и `research/app-demo-object/`. Копии в этой папке обновляются копированием файлов `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`.

Примечание: все страницы под `https://<аккаунт>.github.io/` делят одно хранилище браузера (localStorage, IndexedDB); здесь используются отдельные ключи `camMeasR04Trials` и `hmDemoObject`.
