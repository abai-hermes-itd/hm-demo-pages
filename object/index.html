Объект

ПРОТОТИП окна «Объект» для демонстрации (кадастровый номер, GPS, 2ГИС). Не часть приложения: данные хранятся только на этом телефоне. Версия .
Вводится вручную. Формат пока не проверяется (только пробелы по краям и длина до 40 знаков).
